# Material de la cátedra

Dejen acá todo el material de **Dirección de Proyectos** que deba usarse como marco teórico: apuntes, presentaciones, guías de trabajos prácticos, normas y plantillas que dé la materia.

Claude lee esta carpeta **antes** de aplicar cualquier teoría. Si está vacía o no cubre el tema, pregunta al equipo en lugar de asumir PMBOK, ISO 21500/21502 o PRINCE2.

**Formatos:** PDF, DOCX, PPTX y MD se leen sin problema. Si un PDF es escaneado (imagen), avisen para hacer OCR.

**Sugerencia de orden** (opcional, ayuda a citar después):

```
catedra/
├── 01-apuntes/          teoría por unidad
├── 02-presentaciones/   clases
├── 03-plantillas/       formatos que exige la materia
└── 04-consignas/        guías de TP y criterios de evaluación
```

Si el material tiene una denominación particular para un documento o proceso (por ejemplo, cómo llama la cátedra al documento de inicio del proyecto), **se usa esa denominación**, no la del estándar internacional.
